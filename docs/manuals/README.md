# Manuals and official docs

[Eugene Fight Club playback rig](../../README.md)

Device, what it does in this rig, the official page that loaded when this index was built, and a local copy only when the manufacturer hosts the file publicly. A link is not a local copy. Prices and “Unknown” rows stay in the [parts list](../parts-list.md).

Auracle X is iConnectivity’s configuration program for the X-series and for the PlayAUDIO1U (routing, RTP, the USB host port, audio, control ports, and presets). The product page is [Auracle X](https://www.iconnectivity.com/auracle-x-series). The manuals index lists [Auracle X User Guide 2.6](https://www.iconnectivity.com/s/auracle-x-user-guide-260-20261013.pdf) (13 October 2026). iConfig is the older iConnectivity configurator. No iConfig manual for the PlayAUDIO1U was found on that site. Use Auracle X.
