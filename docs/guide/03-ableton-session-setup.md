# 03. Ableton session setup

[Start here](00-start-here.md)

Build one perform set and put the same set and the same samples on both M1 Minis. AbleSet warns that different sets change song jumps. [AbleNet](https://ableset.app/docs/ablenet).

## Tracks

Use the suggested map in the [cable schedule](../cable-schedule.md): click, cues, backing, drums, synth/bass, FX, spare. Click and cues must not route to the house pair.

Route those tracks to the same PlayAUDIO1U outputs on both computers. iConnectivity’s redundancy guide asks for identical output routing. [Cases](../cases-and-rack-layout.md).

## LifeSine

On the Main set only, put iConnectivity’s free LifeSine plugin on a track and send it to output 15. A blinking shield on the PlayAUDIO1U means it is armed. Do not patch output 15 to the XR18.

## Locators for AbleSet

Put a locator named as the song at the start of each song, on a downbeat if you can. Section names start with `>`. `SONG END` closes a song. `+LOOPFULL` finishes a loop before a jump. The full notation is [AbleSet’s locator page](https://ableset.app/docs/locator-notation), summarized in [ableset.md](../ableset.md).

## Video tracks

Live plays QuickTime `.mov` in Arrangement View, one video window. [Ableton’s video chapter](https://www.ableton.com/en/live-manual/12/working-with-video/). The window hides when Live loses focus. See [Video](../video-projectors.md).

## Templates

Keep two Live templates: record and perform. Save one XR18 scene and one Audio MIDI Setup configuration per mode. [Modes](../modes-and-checklists.md).

## Sample rate

Pick one rate the PlayAUDIO1U supports (44.1, 48, 88.2, or 96 kHz) and use it on the XR18 only after the XR18 manual confirms that rate. **Unverified:** the XR18’s list, until you read [the X AIR manual](https://mediadl.musictribe.com/media/PLM/data/docs/X-AIR/M_BE_0605-AAA_X-AIR_EN.pdf).
