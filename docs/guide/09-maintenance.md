## macOS and Live updates

**Unverified:** a freeze date or a “do not update after X” policy. The plan does not set one.

Before a run of shows, update only when you can repeat the failover drill in [the runbook](../../SHOW-DAY-RUNBOOK.md): LifeSine shield, pull USB A, Sync Playback Now, HDMI switch input 2, AbleNet peers. Apple’s network-MIDI labels can change between macOS versions. Re-check Configure Network Driver after an update. [RTP-MIDI setup](../rtp-midi-setup.md).

Ableton’s license covers two computers the registered user owns, which matches Main and Backup. [License policy](https://help.ableton.com/hc/en-us/articles/209772745-License-policy-for-Live). Live 13 is due in early 2027. That sentence is in [modes](../modes-and-checklists.md). Do not upgrade mid-tour without the drill above.

## Backups

The record checklist says to back up the session before recording. Perform mode needs the same set on both Minis. **Unverified:** a third copy’s location. Keep one copy that is not inside either Mini.

## Batteries and RF

Charge IEM and wireless batteries the day before. Chemistry and hours are not in the plan, because the IEM model is not confirmed. [IEM mixes](../iem-mixes.md).

## Spares the plan already implies

- A second USB-C cable for each DAW port. Two ship with the PlayAUDIO1U.
- A spare 1/4 in TRS for the footswitch.
- A short Ethernet cable.
- The Enttec, if lighting must return after a Main failure, still needs the Lightkey license on a live Mac. A second license is optional and unpriced. [Lighting](../lighting-lightkey.md).

**Unverified:** a formal spare-parts buy list beyond that.
